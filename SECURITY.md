```powershell

# Settings > Audio > Enable Virtual Audio Cable

# Set as microphone
# Discord > Settings > Voice > Input Device = Soundpad (Virtual Audio Device)

# Restart Discord
# Close and reopen Discord after changing audio device
```

### Hotkeys not working

```powershell
# Check hotkey conflicts
# Settings > Hotkeys > Verify no conflict with game controls

# Run as admin
# Right-click Soundpad > Run as Administrator
```
